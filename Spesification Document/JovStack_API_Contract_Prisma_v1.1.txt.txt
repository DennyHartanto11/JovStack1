USER
=========================================================

model User {

  id              String @id @default(uuid())
  email           String @unique
  name            String?

  passwordHash    String

  status          UserStatus

  emailVerifiedAt DateTime?

  createdAt       DateTime
  updatedAt       DateTime

  memberships             Membership[]
  refreshTokens           RefreshToken[]
  emailVerificationTokens EmailVerificationToken[]
  passwordResetTokens     PasswordResetToken[]
  auditLogs               AuditLog[]

}

PURPOSE

- Authentication
- Identity Management
- Ownership

=========================================================
EMAIL VERIFICATION TOKEN
=========================================================

Supports

FR-102 Verify Email

model EmailVerificationToken {

  id        String @id @default(uuid())

  userId    String

  token     String @unique

  expiresAt DateTime

  createdAt DateTime

  user User

}

RULES

- Token stored as hash
- Single use
- Expiration enforced
- Deleted after verification
